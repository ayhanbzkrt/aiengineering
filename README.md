# 🇹🇷 Türkçe

## Proje Hakkında

**AI Engineering Beceri Haritası**, yapay zekâ mühendisliğinin temel yetkinliklerini keşfetmek, öğrenme hedefleri oluşturmak ve mesleki gelişimi takip etmek amacıyla geliştirilen etkileşimli, iki dilli bir öğrenme ve kariyer planlama platformudur.

AI’Han Academy kapsamında geliştirilen platform; yapay zekâ uygulamaları, yazılım mühendisliği, kodlama ajanları ve ürün geliştirme süreçlerini bütüncül bir beceri haritasında bir araya getirir.

Uygulama yalnızca hangi becerilerin önemli olduğunu göstermekle kalmaz; öğrenme kazanımları, kavram açıklamaları, uygulama önerileri, kaynaklar ve kişisel değerlendirme araçları aracılığıyla kullanıcıların gelişim süreçlerini yapılandırmalarına yardımcı olur.

## Platformun Kapsamı

- **4 ana yetkinlik alanı**
- **20 temel beceri**
- **80 öğrenme kazanımı**
- Etkileşimli SVG beceri haritası
- Kişisel ilerleme ve kazanım takibi
- Kariyer rollerine göre beceri değerlendirmesi
- Öğrenme ve gelişim yolculuğu
- Aranabilir ve filtrelenebilir kaynak kütüphanesi
- Kişisel beceri profili ve radar grafiği
- Yapay zekâ destekli mentör entegrasyonu
- Türkçe ve İngilizce arayüz
- Açık ve koyu tema
- Mobil ve masaüstü uyumlu tasarım

## Dört Ana Yetkinlik Alanı

### 01 — Yapay Zekâ Uygulamaları Geliştirmek ve Yayına Almak

Üretken yapay zekâ uygulamalarının geliştirilmesi, büyük dil modelleri, veriyle temellendirme, yapay zekâ ajanları, model değerlendirme ve üretim ortamlarında güvenilir sistemlerin oluşturulması gibi konuları kapsar.

### 02 — Yazılım Mühendisliği Temelleri

Yapay zekâ uygulamalarını sürdürülebilir, güvenli, ölçeklenebilir ve bakım yapılabilir yazılım sistemlerine dönüştürmek için gereken mühendislik yetkinliklerine odaklanır.

### 03 — Kodlama Ajanlarını Kullanmak

Yapay zekâ destekli kodlama ajanlarının yazılım geliştirme süreçlerinde kullanılması, görevlerin planlanması, kodun değerlendirilmesi ve insan–ajan iş birliğinin geliştirilmesini ele alır.

### 04 — Ürün Geliştirme Sürecini Şekillendirmek

Teknik becerilerin ürün geliştirme, kullanıcı ihtiyaçları, karar alma ve ekipler arası iş birliği süreçleriyle bütünleştirilmesini konu edinir.

## Temel Özellikler

### Etkileşimli Beceri Haritası

SVG tabanlı görsel harita üzerinden dört ana yetkinlik alanı ve bunlara bağlı beceriler keşfedilebilir. Her becerinin ilerleme durumu harita üzerinde görselleştirilir.

### 80 Öğrenme Kazanımı

Her beceri dört ayrı öğrenme kazanımıyla ilişkilendirilmiştir. Kullanıcılar tamamladıkları kazanımları işaretleyerek gelişimlerini takip edebilir.

### Beceri Ayrıntıları

Becerilerin ayrıntı ekranlarında öğrenme kazanımlarına ek olarak temel kavramlar, uygulama önerileri, yaygın hatalar ve ilgili öğrenme kaynakları sunulur.

### Kariyer Odaklı Değerlendirme

Farklı mesleki roller için önemli beceriler incelenebilir ve kişisel ilerleme bu rollerin gereksinimleriyle karşılaştırılabilir.

### Öğrenme Kaynakları Kütüphanesi

Kaynaklar; beceri, kaynak türü ve sağlayıcı gibi ölçütlerle aranabilir, filtrelenebilir ve sıralanabilir.

### Kişisel Beceri Profili

Kullanıcıların öz değerlendirmeleri ile tamamladıkları kazanımlar radar grafiği üzerinden karşılaştırılır. Geliştirilmesi gereken alanların belirlenmesi kolaylaştırılır.

### YZ Mentör

Uyumlu çalışma ortamlarında yapay zekâ mentör aracılığıyla kişiselleştirilmiş öğrenme planları oluşturulabilir ve yapay zekâ mühendisliği hakkında sorular sorulabilir.

**Önemli:** YZ mentör ve bulut eşitleme işlevleri çalışma ortamının sağladığı entegrasyona bağlıdır. Normal bir web tarayıcısında veya GitHub Pages üzerinde otomatik olarak etkinleşmez.

### İlerleme Takibi ve Dışa Aktarma

Kazanım ve değerlendirme bilgileri tarayıcının yerel depolama alanında saklanabilir. Kullanıcılar ilerlemelerine ilişkin Markdown raporu oluşturabilir.

## Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- SVG
- Web Storage API (localStorage)
- Responsive Web Design
- İsteğe bağlı Claude entegrasyonu
- Google Fonts (Manrope ve Unbounded)

Proje, ayrı bir JavaScript framework'ü veya derleme sistemi gerektirmeyen tek HTML dosyası yaklaşımıyla geliştirilmiştir.

## Kurulum ve Kullanım

1. Projeyi GitHub üzerinden indirin veya klonlayın.
2. `index.html` dosyasını modern bir web tarayıcısında açın.
3. Dil seçeneğinden Türkçe veya İngilizceyi belirleyin.
4. Beceri haritasını keşfedin.
5. Öğrenme kazanımlarını tamamladıkça işaretleyin.
6. Beceri profilinizi oluşturun ve gelişiminizi takip edin.

### GitHub Pages ile Yayımlama

1. Projeyi bir GitHub deposuna yükleyin.
2. `index.html` dosyasını deponun ana dizinine yerleştirin.
3. **Settings → Pages** bölümüne gidin.
4. **Deploy from a branch** seçeneğini kullanın.
5. `main` dalını ve `/ (root)` klasörünü seçin.
6. Değişiklikleri kaydedin.

Projenin temel özellikleri statik web sitesi olarak yayımlanabilir.

**Not:** Google Fonts ve haricî öğrenme kaynaklarına erişim internet bağlantısı gerektirir. YZ mentör ve bulut eşitleme özellikleri ise ayrıca desteklenen bir entegrasyona ihtiyaç duyar.

## Eğitim Yaklaşımı

Platform şu öğrenme döngüsünü desteklemeyi amaçlar:

Kazanım işaretleme ve öz değerlendirme sonuçları kişisel takip amacı taşır; bağımsız olarak doğrulanmış bir yeterlilik belgesi veya resmî sertifika niteliğinde değildir.

# 🇬🇧 English

## About the Project

**AI Engineering Skills Map** is an interactive bilingual learning and career development platform designed to help users explore essential artificial intelligence engineering competencies, define learning objectives, and track professional growth.

Developed as part of **AI’Han Academy**, the platform brings together AI application development, software engineering, coding agents, and product development practices within a unified skills map.

Rather than simply listing technical competencies, the platform provides structured learning outcomes, conceptual explanations, practical project suggestions, curated resources, and self-assessment tools.

## Platform at a Glance

- **4 competency pillars**
- **20 core skills**
- **80 learning outcomes**
- Interactive SVG skills map
- Personal progress tracking
- Career-oriented skill assessment
- Structured learning journey
- Searchable and filterable resource library
- Personal skill profile and radar visualization
- AI mentor integration
- Turkish and English localization
- Light and dark themes
- Responsive desktop and mobile interface

## Four Competency Pillars

### 01 — Building and Deploying AI Applications

Explore the skills involved in developing and deploying AI-powered applications, including large language models, grounding techniques, AI agents, evaluation methods, and reliable production systems.

### 02 — Software Engineering Fundamentals

Develop essential engineering skills for building maintainable, secure, reliable, and scalable software systems that support AI applications.

### 03 — Using Coding Agents

Explore AI-assisted software development, agent-based coding workflows, task planning, code evaluation, and effective human–agent collaboration.

### 04 — Shaping the Build

Connect technical implementation with product thinking, user needs, decision-making, development processes, and cross-functional collaboration.

## Key Features

### Interactive Skills Map

An SVG-based visualization allows users to explore the four competency pillars and their associated skills. Individual progress is represented visually across the map.

### 80 Learning Outcomes

Each of the 20 skills contains four learning outcomes. Users can mark completed outcomes and track their development over time.

### Detailed Skill Exploration

Skill details include learning objectives, important concepts, suggested practical projects, common pitfalls, and related educational resources.

### Career-Oriented Skill Assessment

Users can explore skill priorities associated with different professional roles and compare their progress with role-specific expectations.

### Learning Resource Library

Discover educational materials through search, filtering, and sorting options based on skills, resource types, and providers.

### Personal Skills Profile

A radar visualization compares self-assessed capabilities with completed learning outcomes, supporting reflection and identification of development priorities.

### AI Mentor

In supported environments, an integrated AI mentor can generate personalized learning plans and answer questions related to AI engineering.

**Important:** The AI mentor and cloud synchronization require compatible runtime integration. They are not automatically available in ordinary browsers or on GitHub Pages.

### Progress Tracking and Export

Learning progress and self-assessment information can be stored locally in the browser. Users can also export their progress as a Markdown report.

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- SVG
- Web Storage API (localStorage)
- Responsive Web Design
- Optional Claude integration
- Google Fonts (Manrope and Unbounded)

The application follows a single-file architecture and does not require a separate JavaScript framework or build pipeline.

## Getting Started

1. Download or clone the repository.
2. Open `index.html` in a modern web browser.
3. Select Turkish or English.
4. Explore the interactive skills map.
5. Mark learning outcomes as completed.
6. Build your personal skills profile and monitor your progress.

### Deploying with GitHub Pages

1. Upload the project to a GitHub repository.
2. Place `index.html` in the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` directory.
6. Save the configuration.

The core application can be deployed as a static website.

**Note:** External learning resources and Google Fonts require internet access. The AI mentor and cloud synchronization require an additional supported integration.

## Educational Approach

The platform promotes a continuous learning cycle:

**Explore → Learn → Apply → Assess → Improve**

It aims to help learners identify relevant competencies, establish learning goals, monitor progress, and plan their next development steps.

Completion tracking and self-assessment are intended for personal learning purposes. They do not constitute independently verified professional certification.
